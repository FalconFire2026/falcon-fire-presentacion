# Presentación comercial Falcon Fire

Presentación interactiva (un solo archivo: `index.html`). Los videos de YouTube cargan cuando se abre desde una dirección web (https) con internet.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `presentacion-falcon-fire`).
2. Sube los archivos de esta carpeta (`index.html`, `.nojekyll`, `README.md`).
3. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, carpeta `/ (root)` → Save.
4. En 1-2 minutos queda en `https://TU-USUARIO.github.io/presentacion-falcon-fire/`.

Nota: en un repositorio público cualquiera con el enlace puede verla. Para que sea privada usa un repositorio privado con GitHub Pro, o un hosting con contraseña.

## Alternativa más rápida
Entra a https://app.netlify.com/drop y arrastra la carpeta: te da un enlace al instante.

## Actualizar
Reemplaza `index.html` por la versión nueva y haz commit.
